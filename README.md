📚 OAU Post UTME Tutor

A responsive web application designed to help students prepare for Nigerian Post-UTME examinations through timed, interactive multiple-choice practice.

✨ Features

- 📖 Multiple Subjects — Practice Mathematics, Physics, Chemistry, Biology, and Aptitude.
- ⏱️ Selectable Exam Timer — Choose an exam duration before starting.
- 📝 Multiple-Choice Questions — Practice questions in an exam-like environment.
- 📊 Automatic Scoring — Get your score immediately after submitting an exam.
- 💡 Answer Explanations — Review explanations for questions after answering them.
- 🧮 Built-in Calculator — Perform calculations without leaving the app.
- 🖼️ Image-Based Questions — Supports questions that require images.
- 🎯 Question Progress — Keep track of your progress throughout an exam.
- 📱 Responsive Design — Designed to work across phones, tablets, and desktops.
- 🏠 Home & Back Navigation — Easily move between different sections of the app.

🛠️ Built With

- HTML5
- CSS3
- JavaScript

No frameworks or external JavaScript libraries are required.

🚀 Getting Started

Use the App

Try the live application: https://oau-post-utme.vercel.app/

Open the app in your browser and start practicing.

Run Locally

1. Clone the repository:
   
   git clone https://github.com/muhammadsala597/oau-post-utme.git

2. Open the project folder.

3. Open "index.html" in your browser.

That's it — no build tools or installation required.

▶️ How to Use

1. Open the app.
2. Choose a subject.
3. Select an exam duration.
4. Answer the questions.
5. Navigate between questions using the navigation controls.
6. Use the built-in calculator when needed.
7. Submit the exam.
8. View your score and review the available explanations.
